- gh CLI không có sẵn trên macOS — cài qua: brew install gh
- Global commands (~/.claude/commands/) phải flat — Claude Code không đọc subfolder
- GitHub repo dùng folder-per-skill để đúng chuẩn create-skill; companion files là con của skill folder
